# 代码检视缺失明细补全设计

## 目标

为 `code-review-statistics-restored.md` 中缺失的 20260611、20260618、20260625、20260709 逐报告明细生成模拟数据，同时保留图片还原出的原始汇总。

## 数据约束

- 报告数量分别为 8、1、4、12。
- 每个日期的检出数、Critical、High、Medium、Low、接收数必须与“各版本汇总”一致。
- 每个日期的前端/后端检出数及接收数必须与“各版本前后端对比”一致。
- 每行检出数必须等于该行 `C + H + M + L`。
- 每行接收数不得超过检出数；有效率按 `接收 ÷ 检出` 四舍五入至一位小数。
- 报告名沿用 `前端/后端 + AMP/AMS-WOA + 版本号_编号` 的既有形式。

## 内容边界

- 新增明细必须显式标注为模拟生成，不冒充图片中的原始数据。
- 现有图片转录内容保持不变。
- 原图的各日期 High 合计为 358，而总计行和前后端汇总均写作 360；本次以各日期行作为新增明细的约束，不擅自修改原始汇总。

## 验证

用确定性脚本解析新增表格，逐行及逐日期检查报告数量、严重级别、检出数、接收数、有效率和前后端拆分。任何一项不匹配都视为失败。
