# 过程文件说明与模板

所有过程文件存储在 `.migration/` 目录下。

## 文件总览

```
.migration/
├── state.json               # Agent 状态跟踪（机器用）
├── memory.json              # 迁移记忆（机器用）
├── source-analysis.md       # 源项目分析报告
├── target-analysis.md       # 目标项目分析报告
├── inventory.md             # ★ 待迁移清单（用户可编辑）
├── plan.md                  # ★ 迁移计划（用户可编辑）
├── conversion-guide.md      # 项目专属转换指南
├── progress.md              # 进度看板（自动更新）
└── validation-report.md     # 校验报告
```

---

## 用户交互点

| 时刻 | 用户操作 |
|------|---------|
| Phase 0 完成 | 确认源/目标项目路径 |
| Phase 1 完成 | 阅读 source-analysis.md，确认准确 |
| Phase 2 完成 | 阅读 target-analysis.md，确认准确 |
| Phase 3 完成 | 编辑 inventory.md 和 plan.md，确认范围 |
| Phase 4 完成 | 阅读 conversion-guide.md，确认规则 |
| Phase 5 每批次前 | 指定本次迁移几个任务 |
| Phase 6 完成 | 查看 validation-report.md |

---
