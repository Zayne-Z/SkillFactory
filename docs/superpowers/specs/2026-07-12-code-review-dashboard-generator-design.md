# AI 代码检视月度看板生成器设计

## 目标

把当前一次性 HTML 看板升级为可重复执行的月度生成流程。Markdown 的章节与表格列保持不变，每月新增最新版本数据后，通过一条命令重新生成静态 HTML。

生成结果继续使用“质量观测站”视觉语言，并在总体价值之外重点展示最近一个版本日的完整情况。

## 使用方式

```bash
node code-review-dashboard/scripts/render-dashboard.js \
  --md code-review-statistics-restored.md \
  --out code-review-skill-dashboard.html
```

命令参数：

- `--md`：输入 Markdown 文件，必填。
- `--out`：生成的独立 HTML 文件，必填。
- `--template`：可选模板路径；默认使用 `code-review-dashboard/templates/dashboard.html`。

## 文件职责

```text
code-review-dashboard/
├── templates/
│   └── dashboard.html       # 固定视觉结构与内嵌 CSS
├── scripts/
│   └── render-dashboard.js  # 参数解析、Markdown 解析、校验与渲染
└── README.md                # 月度更新命令与数据口径说明
```

输出文件 `code-review-skill-dashboard.html` 是无外部资源依赖的完整 HTML，可直接双击打开。

## Markdown 数据契约

生成器读取以下固定章节：

1. `## 一、各版本汇总`
2. `## 三、前端 vs 后端汇总`
3. `### 各版本前后端对比`
4. `## 四、趋势分析`

逐报告明细不是核心看板数据源。当前 Markdown 中部分逐报告数据为模拟补全，生成器不得使用模拟报告名称或模拟严重级别分配形成价值结论。

日期按 `YYYYMMDD` 解析并升序排列。最大日期自动成为“最近版本”，其前一个日期成为对比基准。

## 校验与口径处理

生成前必须校验：

- 每个版本的 `Critical + High + Medium + Low = 检出问题数`。
- 每个版本的 `接收问题数 <= 检出问题数`。
- 问题有效率等于 `接收问题数 ÷ 检出问题数` 四舍五入至一位小数。
- 前端检出与后端检出之和等于版本检出。
- 前端接收与后端接收之和等于版本接收。
- 趋势表的检视报告数与平均每报告检出数可解析。

总计行若与逐版本合计冲突，以逐版本可闭合合计作为图表值，并在页脚自动生成口径说明。例如当前 High 的版本合计为 358，而原图总计行记为 360，HTML 展示 358 并说明差异。

前端或后端检出为 0 时，有效率显示为 `—` 和“无报告”，不得显示 `0%`。

必要章节、列或数字缺失时，生成器以非零退出码失败，不覆盖已有输出文件。

## 页面信息结构

### 1. 总体价值

保留顶部“质量观测窗”，展示累计检出、确认有效或已修复、总体有效率、版本数量和检视报告数量，并说明 Skill 为开发流程提供可行动的质量反馈。

### 2. 最近版本观测

紧接总览，成为页面第二视觉中心。自动展示：

- 最近版本日期。
- 检出、接收、有效率、报告数量和平均每报告检出。
- Critical、High、Medium、Low 数量。
- 前端与后端的检出、接收和有效率。
- 相对上一版本的报告数、检出数、接收数和有效率变化。
- 无报告、小样本或分母为零时的明确说明。

页面只陈述可验证变化，不把版本波动描述为持续单调提升。

### 3. Skill 作用链

保留团队使用、发现问题、开发者确认、反馈质量改进四步链路。

### 4. 双轨趋势图

图表默认显示最近 8 个版本：

- 上轨：检出数柱状图，数字固定放在柱顶安全区域。
- 下轨：问题有效率折线图，每个数值放在独立等宽标签带内。
- 两轨共用日期轴，但数据标签不共享绘图空间，从结构上避免文字堆叠。
- 超过 8 个版本时，只截取最新 8 个用于趋势图；所有版本仍进入历史区。

### 5. 团队覆盖与版本历史

- 团队覆盖只展示前端/后端检出、接收和有效率，不展示存在口径冲突的严重级别汇总。
- 历史区为每个版本生成完整卡片。版本数量增加时页面自然向下延伸，不隐藏旧版本。

### 6. 数据说明

自动输出总计冲突、模拟明细边界、报告数量字段来源等说明。

## 视觉规则

- 延续雾蓝背景、深海青文字、Skill 价值绿、风险琥珀和辅助蓝。
- 顶部圆弧“质量观测窗”仍是品牌标志元素。
- 最近版本区使用横向观测带和更强的日期排版，不复制顶部圆形仪表。
- 图表保持细网格、明确单位和固定标签轨道，数据可读性优先于装饰。
- 页面适配 1440px、768px、375px，并支持打印。

## 测试与验收

- 使用当前 Markdown 生成的数字与现有看板一致。
- 用增加一个新版本的测试 Markdown 验证最近版本会自动切换、对比基准同步更新。
- 用超过 8 个版本的测试数据验证趋势图只显示最近 8 个、历史卡片显示全部版本。
- 用缺列、无法闭合、`0/0` 和总计冲突数据验证错误与口径说明。
- SVG 中柱状图文字与折线图文字属于不同轨道；三档浏览器截图中无重叠和横向溢出。
- 输出 HTML 不含外部依赖、模板占位符或控制台错误。
